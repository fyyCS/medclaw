Method

Nothing is trained. The library is what learns.

A text-only orchestrator reasons about where to look but never sees a pixel. Frozen vision sub-agents execute each call. Competence accrues in an external skill library, not in any weight.

Orchestrator

Opus-4.8, frozen. Emits a tool call, reads the textual observation, decides again, and stops when it can answer. Because it cannot see the video, every visual need becomes an explicit call — so the whole trajectory is auditable.

Vision sub-agents

A video expert (Gemini-3.1-flash-lite / 3.5-flash) handles anything spanning time; a frame verifier (GPT-5.5) gives an independent higher-resolution read of a single instant. Both frozen, both swappable.

view_full_video

Localizes where. A low-res pass over the whole procedure emits a timeline and a candidate window; a second pass re-watches that window at higher resolution and returns the tight sub-window.

crop_video

Inspects what happens in a chosen range, re-read at crop resolution. This is the call directed re-look aims at the adjacent window.

select_video_frame

One frame at one timestamp, described by a different model — a cross-model check on a specific instrument or action.

crop_video_frame

A normalized spatial region of one frame, for separating small or overlapping structures.

search_surgical_kb

Retrieval over 1,039 PubMed-derived passages, FAISS + cosine. General surgical background only — no benchmark answers.

directed_re-look

The skill the loop discovered, not one we wrote. For a before/after question, crop the window adjacent to the located event and ground the answer there.

Heuristic Skill Distillation — how a skill gets in
1

Answer blind, then look at the gold

On a 60-question mining set the agent answers with the same tools it uses at test time, then is shown the reference answer.

2

Diagnose the gap

Operational (a different way of looking would have caught it), unreachable (no amount of looking recovers it), or already correct. Only the first carries a lesson.

3

Write the rule, operationally

The agent writes the skill itself, and it must change how it looks — never what the answer should assert. Learning wording from an unreachable gold just teaches confident hallucination.

4

Gate it on reward

Install one candidate, re-answer a 40-question validation set, re-judge. Keep it only if the four-dimensional mean rises by more than 0.05 and no single question drops two points. A rejected skill leaves no trace.

MedClawBench

Long videos, expert golds, and four shortcuts closed.

Every question must survive filters that certify it can be answered only by watching the moment it targets: not from priors alone, not from a whole-procedure summary, not by listening to the narration, and — for neurosurgery — not unless it matches the neurosurgeon's own interval annotation.

Get the data

Questions ship now. Videos come from two places.

SVU lecture split

The held-out test split of SVU-31K — 141 videos, publicly downloadable. Each clip is stored under its SVU-31K id, so files drop straight into place. 

# 864 questions over 141 lecture videos
huggingface-cli download gkw0010/SVU-31K \
    --repo-type dataset --local-dir SVU-31K

Neurosurgery split

259 questions over 15 recordings from Beijing Tiantan Hospital, grounded in a neurosurgeon's interval annotations. Because this is identifiable clinical footage, the videos are not yet public — they will be released through an application process. The questions and golds are already in the benchmark file. 

# questions ship with the repo
data/surgical_vqa/benchmark_final_1123_anon.jsonl

Reproduce the tables

# run the agent (lite backbone on SVU, flash on neurosurgery)
export SURG_VIDEO_MODEL=gemini-3.1-flash-lite
export SURG_SKILL_TOOLSET=1
python scripts/open_baseline_hermes.py --src <questions>.jsonl --out <answers>.jsonl

# score: four dimensions, 1-5, broken down by VTR / VPR
python surg_env/score_final.py --split neuro
python surg_env/score_final.py --split svu
